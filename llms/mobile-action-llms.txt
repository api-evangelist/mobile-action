# MobileAction

> MobileAction is an app-store marketing intelligence platform used by 5,000+ mobile app and game companies for App Store Optimization (ASO), Apple Ads campaign management, ad-creative intelligence and market benchmarking. It is an InMobi Advertising company. Two machine surfaces are published: a credit-metered REST API at https://api.mobileaction.co authenticated with an account API key in the `token` query parameter, and a remote MCP server at https://mcp.mobileaction.co/mcp exposing 88 tools over the same credit allowance. There is no OpenAPI document.

## API

- [MobileAction API docs](https://docs.mobileaction.co/): REST intelligence API. Base URL https://api.mobileaction.co. Auth: API key via `token` query parameter. Metered in credits (X-Credit-Cost / X-Credit-Remaining / X-Credit-Reset headers; balance via GET /api-key).
- [Getting started / introduction](https://docs.mobileaction.co/guide/introduction): base URL, authentication, the per-endpoint credit table, and the App Store / Google Play category id tables.
- [API Solutions](https://www.mobileaction.co/api-solutions/): what the API covers and who it is for. Access is enterprise-only and arranged through sales.

## MCP (remote agent surface)

- [MCP server setup](https://docs.mobileaction.co/mcp/server-setup): endpoint `https://mcp.mobileaction.co/mcp`, authenticated by appending `?token=YOUR-API-TOKEN`. Treat the tokened URL as a password.
- [What is MCP](https://docs.mobileaction.co/mcp/what-is-mcp): MCP is additive to the REST API — exploration and ad hoc analysis via MCP, production pipelines via REST. Both draw the same credits.
- [Connect to Claude](https://docs.mobileaction.co/mcp/connect-to-claude) · [Connect to ChatGPT](https://docs.mobileaction.co/mcp/connect-to-chatgpt) · [Connect to Gemini CLI](https://docs.mobileaction.co/mcp/connect-to-gemini-cli)
- 88 tools, MCP protocol 2025-06-18, server MobileAction 3.4.7. `tools/list` is readable anonymously; invocation requires the key.

## Service areas

- App Store: keyword rankings and history, top keywords, keyword metadata, organic keywords, impression share, share of category, category rankings, top charts, app detail, version timeline, developer apps, reviews, review word analysis, download/revenue estimations, featuring analysis.
- Google Play Store: the same surface under `playstore-` / `googleplay_` names, with `langCode` in place of `countryCode` on app-info endpoints.
- Ad Intelligence: creatives, advertiser/publisher badge, and distributions by country, language, network, creative type and creative dimension. Top advertisers by category and country.
- CPP Intelligence: Custom Product Pages by app, by keyword and by category, plus a CPP's paid keywords.
- Search Ads / CMP: Apple Ads integrations, MMP integrations, goals, apps, ASA + MMP reports, TOP_APPS reports, bid history logs, paid keywords, paying apps.
- Dashboard (account-scoped, the only writes): tracked apps, daily keyword rankings, add/delete tracked keywords, app search, sales metrics, retention history, keyword spots, max reach and install estimations.
- Other: cross-store app match, visibility scores (current and historical).
